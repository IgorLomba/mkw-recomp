# tools/shaders

| Script | What it does | Usage |
|---|---|---|
| `extract.py` | Extracts every distinct stage of the `.bfsha` (BNSH) and `.sharcb` (agl) files of `romfs/Shader` to `build/shaders/<sha1>.{ctl,code}` with `index.csv` (stage, size, origin). Size from `control+0x44`; cuts at the first null word or at the next program's SPH. It also looks for BNSH in the rest of the romfs (effects, layouts), agl packages inside `.sarc` (`Lib/agl/agl_resource...sarc`) and the decompressed image of the NSOs (two BNSH in `main`): 11 492 stages; `--shader-dir` only looks at `romfs/Shader` (4 196) | `uv run tools/shaders/extract.py [--shader-dir] [--everything]` (~10 s: only `Effect`, `Layout` and `Lib` outside `Shader`, where 1.0.0 keeps every stage; `--everything` reads all 21.7 GiB, ~46 s warm) |
| `embed_spv.py` | Compiles one of the runtime's own shaders (`runtime/shaders/X.comp`) with `glslc` and writes it as an array in `runtime/gfx/vk/X_spv.h` | `uv run tools/shaders/embed_spv.py runtime/shaders/bc7_encode.comp` |
| `decode_check.py` | Compares the `sm86/decode` decoder with `nvdisasm` on every instruction of every program | `uv run tools/shaders/decode_check.py` (~25 s; needs `census.py` and `sm86/spec/spec.py` done) |
| `mma_check.py` | Off-GPU test of the translator's matrix functions (`LDSM`, `HMMA`, `MOVM`) thread by thread, against `A·B` and the transpose | `uv run tools/shaders/mma_check.py` (seconds) |
| `operand_check.py` | The same for operands: registers, predicates, constant banks (offset modulo 64 KiB) and `-`/`\|x\|` signs of the decoded fields against `nvdisasm`'s text | `uv run tools/shaders/operand_check.py` (~75 s; needs `census.py`) |
| `shaderc_lib.py` | GLSL → SPIR-V inside the calling process through libshaderc (ctypes): the one beside the package's `glslc` (`lib/libshaderc.so.1`, `shaderc.dll`) or the system's `libshaderc_shared`. `translate.py` uses it when found: 240 programs in 11.7 s against 40.3 s with one `glslc` each, the same SPIR-V (11/11/2026) | imported by `translate.py` |
| `translate.py` | Translates every program to SPIR-V ahead of time (`sm86/translate` → libshaderc in the worker, `shaderc_lib.py`, else `glslc --target-env=vulkan1.3` → `spirv-val`) and counts the failures per instruction: the translator's work list. `--dumped DIR` adds the programs a run did not find (`MKW_SPIRV_DUMP=DIR`): the ones the game generates at run time from templates in `main`. Writes `build/spirv/<key>.{glsl,spv,res.json}`, with key = sha256 of the control section (0xd8 bytes) and the trimmed code: the name the runtime looks up (`nvn2_program_key` in `runtime/gfx/nvn/procs/nvn2.c`) | `uv run tools/shaders/translate.py [--stage ps] [--full]`: only compiles with `glslc` the programs whose GLSL changed since the previous pass (`<key>.result` keeps the verdict; `<key>.done`, with a hash of the translator, skips unchanged programs entirely); `--sample N` checks a change that touches them all on N spread programs; `--glslc`, `--spec`, `--no-validate` and `--progress`, for the player's setup |
| `track_audit.py` | Audit of the translator's per-register tracking (`ur_ssbo`, `ur_derived`, `reg_ssbo`, `fold`) over every program: uses of a value whose register was rewritten afterwards (stale) and uses that cross a branch, at risk if another instruction writes the register. After the fix of 08/11/2026, 0 stale | `uv run tools/shaders/track_audit.py [--examples N]` (~1 min) |
| `glsl_hash.py` | Fingerprint (sha256) of the GLSL and reflection `sm86/translate` gives for each program: a refactor of the translator must not change it | `uv run tools/shaders/glsl_hash.py before.tsv`, the change, again to `after.tsv` and `cmp` (~1 min) |
| `flow_why.py` | One program's branch graph, whether `flow._structure` builds it and where `flow_sim` sees it run other instructions (seed, step, the instructions of each) | `uv run tools/shaders/flow_why.py SHA1 [--stage ps]` |
| `flow_check.py` | Runs `flow_sim` on every program with the unverified structured flow (`flow._structure`) and lists those that would execute other instructions (57 of 7 643 on 31/10/2026; `flow.structure` keeps them as a `switch`). Checked to catch a `flow.py` broken on purpose (11 of 12 programs) | `uv run tools/shaders/flow_check.py [--sample N] [--only SHA1...]` (~3 min) |
| `census.py` | Disassembles each stage with `nvdisasm -b SM86` (local reference, CUDA 12.8 in `scratchpad/nvidia/cuda`) and counts opcodes by instructions and by programs (06/11/2026: 11 561 programs, 5 552 888 instructions, 99 opcodes, none rejected: if `nvdisasm` rejects a program over an illegal word, it cuts it there and retries); leaves each one's `.sass` and `opcodes.csv` in `build/shader_census/` | `uv run tools/shaders/census.py` (~6 min) |
| `glsl_cpu.py` | Runs a translated loop-free FS on the CPU for one pixel, with the UBOs of a pass of an `MKW_DUMP_UBO` dump or of a draw of an `MKW_TRACE_UBO=<FS hash>` trace (compiled as C): the same output as the GPU points at the translator or the data, a different one at the runtime | `python3 tools/shaders/glsl_cpu.py KEY passes.txt|trace PASS|FRAME-N X Y` |
| `fs_bands.py` | Diagnostic FS: each texture sample of a translated FS in its own vertical band of the screen (the last one, the shader's colour); keeps the original in `<key>.spv.orig` | `uv run tools/shaders/fs_bands.py KEY [--restore]` |
| `spec_ceiling.py` | Ceiling of specialization without the GPU: fixes in the SPIR-V the bank words a run's census (`MKW_CB_CENSUS`) saw stable, freezes and optimizes with `spirv-opt`, and counts instructions and branches against the generic one | `uv run tools/shaders/spec_ceiling.py CENSUS.tsv [--keys KEY...] [--top N]` |
| `spec_stats.py` | RADV statistics (instructions, VGPRs) of each specialized pipeline next to its generic one, from the log of a run with `MKW_SPEC_STATS=1` | `uv run tools/shaders/spec_stats.py build/run/NAME.log [--stat Instructions]` |
| `spv_fnv.py` | Program key from the SPIR-V hashes a dump gives (`sh_<hash>.spv`) | `python3 tools/shaders/spv_fnv.py HASH...` |
| `retry_shas.py`, `retry_failed.py` | Translates specific programs of the census again, or the failed ones with a given reason | see their header |
| `classify_missing.py` | Programs dumped by `MKW_SPIRV_DUMP`: whether they are in the census | `python3 tools/shaders/classify_missing.py DIR` |

`nvdisasm` is neither versioned nor distributed. `sm86/spec/spec.py` (the SM86 spec) fetches what it needs; `census.py` and the checks also want
`cuda_cudart` 12.8 from `developer.download.nvidia.com/compute/cuda/redist/`, unpacked in `scratchpad/nvidia/cuda/`.
