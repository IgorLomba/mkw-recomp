# i18n/game/1.8.0

The game texts that version 1.8.0 reworded or retagged (82 per language), in the same `label<TAB>text` format as
`../<lang>.tsv`. `tools/i18n/game_texts.py` reads them over `../<lang>.tsv` when the game copy is 1.8.0 or later, so a
1.0.0 copy keeps its own translation of those labels.

| File | Language |
|---|---|
| `ca.tsv` | Catalan |
| `gl.tsv` | Galician |
| `eu.tsv` | Basque |
